🔹 1. CZĘŚĆ: DANE TRENINGOWE + BAZA DANYCH
Co tu robisz:

- Spotify → tytuł, artysta
- Genius → tekst
- Kaggle → tekst + mood (do trenowania)

Efekt:

- baza Django → realne piosenki użytkowe
- CSV → dane treningowe ML

📌 W pracy:

„W pierwszym etapie projektu pozyskano dane tekstowe utworów muzycznych z wykorzystaniem zewnętrznych API oraz publicznych zbiorów danych.”

🔹 2. CZĘŚĆ: MACHINE LEARNING (SERCE PRACY)

Tu robisz wszystko, co promotor kocha:

Pipeline ML:

1. Detekcja języka
2. Czyszczenie tekstu
3. TF-IDF
4. Klasyfikator (np. Logistic Regression / SVM)
5. Ewaluacja
6. Zapis modelu .pkl

📁 ml/train.py:

model.fit(X_train, y_train)
joblib.dump(model, "models/mood_model.pkl")


📌 W pracy:

„Zaprojektowano i wytrenowano własny model klasyfikacji nastroju utworów muzycznych na podstawie treści tekstowej.”

🔹 3. CZĘŚĆ: INTEGRACJA Z BACKENDEM
Co robi Django:

- bierze tekst piosenki z bazy
- ładuje model ML
- przewiduje nastrój
- zapisuje mood_tag

📁 services/mood_classifier.py:

model = joblib.load("ml/models/mood_model.pkl")

def classify(text):
    return model.predict([text])[0]


📌 W pracy:

„Model został zintegrowany z aplikacją webową w celu automatycznej klasyfikacji nastroju utworów.”
